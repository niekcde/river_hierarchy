The network runner resumes cached JSON runs. Use a fresh output directory if changing the solver, forcing, geometry or test definitions. Do not treat previous caches as new executions. The two environments exchange NPZ files; no MATLAB or additional package installation is needed.

Outputs:
- hydrographs_plotly.html: self-contained interactive comparison, all valid grid families plus MC references; original and collapse lines. No external JavaScript download required.
- hydrographs.png: static overview of key comparisons.
- REPORT.txt: full metrics, tests, failures and interpretation limits.
- main_comparison.csv: valid normal-flow runs selected for spatial comparison.
- all_results.csv: all 32 hydraulic network runs, including two invalid CFL 0.7 runs.
- hydraulic_checks.json, additional_benchmarks.json: verification evidence.
- spatial_checks.csv, timestep_checks.csv, boundary_sensitivity.csv: separate sensitivities.
- mc_resolution_summary.csv: 10 MC runs including exact reproduction of saved reference.
- *_diagnostics.npz: stored profiles at initial/rising/near-peak/falling/final times, all-step depth extrema, and storage histories.
- *_branch_splits.csv: dynamic split fractions at saved times.
- manifest.json: setup and source provenance.
