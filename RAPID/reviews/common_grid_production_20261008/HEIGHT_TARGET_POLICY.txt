DRAFT HEIGHT-TARGET POLICY — 2026-10-08

Purpose: timing is primary; height is a soft secondary objective when observable
and comparable with the modeled boundary conditions. No target bounds adopted.

1. Use the downstream observation of the SAME selected event feature, rather
than the upstream maximum or automatically the downstream global maximum.
Upstream Q is the forcing/reference. Setting downstream target = upstream peak
implicitly asks for no peak attenuation and is not a neutral target definition.
For plateaus or multiple crests, record which statistic is meant (plateau level,
selected crest height, or separate crest levels). Preserve reviewed timing targets.

2. Check comparability before applying a height penalty. Check represented gauge
locations, lateral inflows, diversions, drainage-area differences, gauge quality,
clock alignment, initialization and observation coverage. Downstream peaks above
upstream peaks in the common observation window flag this issue; they do not alone
prove lateral inflow, since antecedent storage and incomplete windows also matter.
The current routing has one supplied inlet, conservative branch allocation and no
new lateral inputs. Do not ask X to manufacture missing flow or exploit numerical
overshoot. A good normalized shape fit is not proof of an absolute amplitude fit.

3. Populate a semi-manual review record for every example:
  - Selected timing feature and source support/cadence.
  - Original measured downstream height(s), on the common reporting support.
  - Raw selected-crest point range for context; NOT an uncertainty interval.
  - Baseline treatment if assessing peak excess instead of absolute discharge.
  - Accepted lower/upper height, units, evidence/rationale and reviewer status.
  - Whether height is eligible for calibration; secondary weight/tolerance.
Bounds must come from measurement/reconstruction/baseline uncertainty or explicit
scientific acceptance criteria, not from widening the range until the model fits.
An optional interval objective is zero height penalty inside accepted [L,U] and
increasing distance outside. Timing admissibility remains a separate primary
constraint. No numeric weight or universal percentage has been selected.

4. Where absolute flows are not directly comparable, do not substitute upstream
height as an observed downstream target. Either represent/correct a demonstrated
boundary mismatch, omit the height objective and retain timing/shape calibration,
or adopt an independently justified attenuation range explicitly as a prior.
The latter is a modeling assumption, not a measured downstream calibration target.

5. A dimensionless alternative, if justified, is downstream peak EXCESS divided
by upstream peak EXCESS, using explicitly reviewed pre-event baselines. Both use
the same upstream reference; do not normalize each curve independently to its
own maximum. Baseline subtraction cannot remove time-varying lateral inflows.
A ratio above one is a comparability flag for this routing setup, not something
to clamp or silently reinterpret. The current display shift is not automatically
an accepted baseline correction for calibration.

6. Choose beta only after that review; fit n conditionally to the existing timing
feature, then compare admissible fits on height and full shape. Do not transfer
beta=.25 to all cases automatically. Apply an accepted per-example calibration
unchanged to its hierarchy children so their differences remain observable.
