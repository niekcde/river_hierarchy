REQUIRED DISCHARGE COMPARISON
For every reach compare:
 A. The allocated reference discharge actually used in Cunge's X/diffusivity.
 B. Q_M = (B/n) h^(5/3) sqrt(S), the discharge implied by prescribed width, depth,
    slope and fitted n under the SAME wide-channel approximation as raw celerity.
Record Q_A/Q_M, both actual values, depth, width, slope, n, raw/capped c, allocation,
reach length, subdivision, K, X and local memory. A ratio is a consistency screen,
not proof that either discharge is the true local flow. Trace depth anchoring,
slope provenance/units, width representativeness and width-based branch allocation.

Counterfactual required depth h_A = [Q_A*n/(B*sqrt(S))]^(3/5) helps quantify the
mismatch. It is not automatically adopted: slope or allocation could instead be
wrong, or uniform-flow assumptions could be unsuitable (e.g. backwater).
Do not independently substitute Q_M for allocated reach Q: this generally breaks
network continuity and must not alter the measured upstream forcing.

HOW THE EVIDENCE MAY JUSTIFY CHANGING X
Preferred: identify defensible hydraulic inputs/state, recalculate c, K and X
consistently, and compare with the unchanged baseline at fixed n. Keep network
flow allocation conservative. Isolate input changes in controlled comparisons.
A depth-only consistency alternative with fixed B/S/Q changes c and K/X but leaves
D=Q/(2BS) unchanged: it must not be promised to cure excessive physical diffusion.
If slope, effective width or allocation changes, explicitly show how D changes.
Do not choose a slope floor, X clip or depth simply because it improves peak fit.

A direct X adjustment remains a possible EMPIRICAL model alternative, not an
established hydraulic correction. If investigated, parameterize an explicit
positive diffusivity multiplier beta: X=0.5-beta*D/(c*dx). beta=1 retains Cunge;
beta<1 reduces assumed diffusivity. Justify any beta range independently, report
it, and validate on independent events where available. If selected using this
same event's peak, call it calibration, not physical validation. No beta has been
selected or adopted. Keep the distinction from fixed-X routing explicit.

VALIDATION BEFORE ACCEPTANCE
Recalculate grid coefficients when changing numerical cell length; compare spatial
refinements as well as existing temporal controls. Check pulse behaviour, flow
nonnegativity, volume/storage accounting and event shape/feature timing, not just
maximum height. Compare initialization alternatives using supported antecedent
observations, without mixing an initialization change into an X-only attribution.
A stable calculation or a visually good fit alone does not establish physical
validity. Very low-slope/backwater conditions may require another routing model.

DECISION
Correct demonstrated input errors first. Compare defensible coherent-state and
numerical alternatives next. If none resolves the mismatch, report a limitation
of the constant-reference model; consider a separately validated variable-state
or hydraulic alternative. Do not launch the full production rerun solely on the
basis of a tuned X or another Manning search.
