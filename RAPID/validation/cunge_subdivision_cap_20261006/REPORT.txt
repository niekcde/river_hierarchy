CUNGE SUBDIVISION SENSITIVITY — 2026-10-06

Question: can the conservative dx <= Ld subdivision rule be relaxed while preserving acceptable routing?

DEFINITIONS AND INTERPRETATION
Ld = Q_reference / (B S c), dx=L/N, K=dx/c, X=0.5*(1-Ld/dx).
Rule A (previous conservative rule): N=max(1,ceil(L/Ld)).
Rule B (cap): N=min(M,max(1,ceil(L/Ld))), M=2,3,4,8,16,32.
Rule C (hydraulic scale multiplier): N=max(1,ceil(L/(alpha*Ld))), alpha=2,3,4,6,8,12,16.
Written literally, max(2,L/Ld) would not reduce 98 sections on the longest link; both plausible relaxations were tested.
Rule C implies X <= (1-1/alpha)/2. It indirectly restricts X through the grid but does not overwrite X. Directly clipping X at fixed dx would change the nominal diffusion coefficient c*dx*(0.5-X). Every rule here preserves Q/(2 B S), total actual length, nominal travel time and nominal variance.

DESIGN
16 parents and their 64 previously selected children, using the anchored hydraulic frames. Within each state, all hydraulics, celerity, Manning n=.035, reference discharges, topology and split fractions held fixed across grids. Q values are the previously frozen state reference allocations; this is not a new reference-allocation or calibration experiment.
Three network forcings: saved event, and sin-squared positive pulses with 12 h / 48 h rise and equal fall durations. dt=15 s; frequency-domain evaluation every 150 s. Both inlet time levels used in the standard Muskingum recurrence, without lateral inflow.
13 new grid rules * 80 states * 3 forcings = 3120 state-hydrograph evaluations, plus existing reference grids.
Native recurrence checked on four selected stress pairs (examples 15,37,48,54), all 13 rules, saved event and 12 h pulse, dt=15 and 7.5 s: 416 runs. These checks include every numerical subsection, not only the network outlet.
Isolated-link experiment: only child 37 / CB001_bubble_3 / edge975 varied, with identical inlet hydrograph taken from the conservative grid. Outlet at anchored node648, upstream node20. Actual L=74274.651476 m, c=3.358991644 m/s, Ld=763.935673892 m. Counts include 1 through16 plus selected values up to743. Saved event and positive 1,12,48 h rise pulses and a step, at both time steps. The 1 h pulse and step are stress tests, not an assertion that observed floods rise this quickly.

STABILITY VERSUS POSITIVITY VERSUS ACCURACY
At these parameters N=1 is already bounded. Therefore there is no largest finite alpha that can be selected merely from boundedness.
For O_t=a I_t+b I_(t-1)+d O_(t-1), the impulse weights are h0=a and hj=(b+d*a)*d^(j-1), j>=1. b+d*a=4*K*dt/[dt+2*K*(1-X)]^2 >0. With 0<=d<1, a>=0 ensures positivity for arbitrary nonnegative forcing, even when b<0.
For Cunge this sufficient positive-response condition is dx <= Ld+c*dt, with dt <= (dx+Ld)/c retained for d>=0. At dt15 this link needs ceil(L/(Ld+c*15))=92 sections; alpha<=1+c*15/Ld=1.065954 is the continuous conservative bound before integer rounding. At dt7.5 it needs95. The dt-independent X<=0 rule needs98.
Fewer sections can work for smooth hydrographs, but that is a forcing-dependent accuracy decision. No universal positive-response guarantee follows from cap2/cap3 or alpha2/alpha3.

RECOMMENDATION
Do not treat98 as a necessary stability count. Two or three sections do not provide adequate protection across the tested forcings; nor does a single relaxed hydraulic multiplier guarantee accuracy across the networks.
For a general positive-response requirement, use N=max(1,ceil(L/(Ld+c*dt))) together with the d>=0 guard, or retain the slightly more conservative dt-independent Ld rule. Recheck after changing dt or hydraulic/calibration parameters.
For fewer sections, define acceptable pulse undershoot, waveform error and parent-child peak-contrast error, then choose the coarsest grid that passes those checks under the fastest relevant forcing. Keep unchanged anchored exterior links on the same grid in parent and child comparisons. This is an empirical tolerance policy, not a new universal stability theorem.
For the specific 74 km link,16 sections greatly reduce the12 h dip; 32 reduces it to roughly0.0001% but does not eliminate artifacts for all sharper forcing. Across64 pairs cap32 limits the tested saved-event contrast differences to6.06 minutes. A tighter required timing tolerance must refine affected reaches further; even the original Ld rule has that6.06-minute worst case.

Literature context: Ponce and Theurer, Accuracy Criteria in Diffusion Routing (1982), https://ponce.sdsu.edu/accuracy_criteria_in_diffusion_routing.html distinguishes bounded routing from accuracy, including negative outflow artifacts on coarse grids. The quantitative conclusions above come from the archived experiments, not that paper.
